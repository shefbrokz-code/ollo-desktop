ollo Code

Агент-программист работает в папке проекта на вашем сервере: читает код, правит файлы, запускает проверки. Права определяются режимом сервера (чтение, с подтверждением, авто).

Сначала добавьте сервер: меню аккаунта → Серверы (SSH).
